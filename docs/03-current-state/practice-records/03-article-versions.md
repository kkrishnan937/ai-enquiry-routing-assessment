# Article versions and change history

Record: H-01  
Article: KB-WASTE-01 - Missed collection intake

## Version 1.0

Published: October 20, 2026  
Editor: Customer Service Supervisor

For a missed collection, record the resident's address, cart type, and missed-collection date. Refer the request to Waste Services for investigation. Provide the request number to the resident. Do not promise a collection date.

## Version 1.1

Published: November 5, 2026, 9:00 a.m.  
Editor: Customer Service Supervisor  
Change reference: E-01

For a missed collection, record the **collection address: the property where the collection was missed**, the cart type, and the date the resident reports it was missed. Do not substitute the resident's contact address when it differs from the collection address.

If the collection address is missing, ask the resident for it before referral. Record the enquiry as awaiting information and retain responsibility for follow-up until the details arrive.

Refer the completed request to Waste Services for investigation. Provide the request number to the resident. Do not promise a collection date.
